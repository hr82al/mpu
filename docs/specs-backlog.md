# Реестр нереализованных спек `mpu`

Один список спек из `ts/docs/specs/`, у которых нет реализации. Статус сверен с живым `mpu --help`
2026-09-10 (и записан в строке «Статус:» самих спек), а не по памяти. Реализована команда —
строку отсюда убрать, статус в спеке поменять на «реализовано» с тем, чем сверено.

⚠️ «Реализовано» в спеках означает «команда есть в справке»; построчной сверки поверхности флагов
со спекой не проводилось — частичные расхождения возможны и сюда не попали.
