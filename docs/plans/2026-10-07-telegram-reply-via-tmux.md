# Ответ из Telegram в сессию — через tmux, без канала (отложено)

Статус: предложение, отложено владельцем 2026-10-07. Серия R —
`ts/docs/specs/telegram-relay-statement.md`; канал — `ts/docs/specs/claude-channel.md`
(R2b); снимок окна — `ts/docs/specs/claude-hook-notification-snapshot.md` (R4).

## Что сейчас

Канал `mpu-channel` (MCP-сервер с возможностью `experimental.claude/channel`)
нужен ровно для одного: доставить в сессию свободный текст владельца из
Telegram в ответ на «ждёт ввода» (R2b). Цена:

- Claude Code грузит канал только с флагом
  `--dangerously-load-development-channels server:mpu-channel` и на каждом
  старте спрашивает «I am using this for local development / Exit»;
- функция `claude` в `~/.bashrc` (ставит `install.sh`) и автоподтверждение
  диалога в `launch.sh` изолированных сессий существуют только ради этого;
- сервер `mpu-channel` в пользовательских настройках Claude Code.

Каналом не пользуются: кнопки вопросов о праве и AskUserQuestion (хук
`PermissionRequest` сам возвращает решение), формы MCP (хук `Elicitation`),
снимок окна для нераспознанных диалогов (R4 — текст и клавиши уже вписываются
в окно tmux с охраной `pane_current_command`).

## Предложение

1. Хук `Stop` знает окно сессии (`TMUX_PANE`) и шлёт «ждёт ввода» — как
   сейчас.
2. Ответ владельца текстом бот вписывает в окно сессии `tmux send-keys -l
   <текст>` и `Enter` — той же охраной, что R4: в окне работает `claude` и
   он ждёт ввода; плюс проверка, что строка ввода пуста (иначе склеится с
   набранным владельцем в терминале) — иначе «не доставлено, ответьте в
   терминале».
3. Уходят: сервер `mpu-channel`, флаг `--dangerously-load-development-channels`,
   функция `claude` в `~/.bashrc`, автоподтверждение в `launch.sh`, спека
   `claude-channel.md` (вердикт — заменена).

## Чем платим

- Сессии вне tmux свободный текст не получают («не доставлено»); кнопки там
  работают как прежде. Рабочие сессии владельца — в tmux.
- Нет пометки «из Telegram»: в сессии ответ выглядит набранным в терминале.
- Многострочный текст — вставкой (`send-keys -l` сохраняет переводы строк
  как ввод Claude Code); проверить живьём.

Отдельной маленькой порцией после E4 этапа 3 (код рядом с путями E1:
`mcp/src`, `back/src/claudehook`, `botquestions`). Сценарии чёрного ящика —
по договору: эмулятор Bot API, подставной `tmux` в `PATH`, снимки экрана из
