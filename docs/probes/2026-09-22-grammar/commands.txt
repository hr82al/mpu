Команды (вывод `help` корня, сокращённо):
  kiten ls        список моих карточек Kaiten
  kiten card      одна карточка Kaiten целиком
  kiten comment   комментарий к карточке Kaiten
  sql-ro          SQL только на чтение на базе, выбранной целью
  sql             SQL с записью на базе, выбранной целью
  process         пересчитать витрины клиента
  logs            логи со стенда (Loki; через portainer — снимок)
  search          найти клиента или таблицу
