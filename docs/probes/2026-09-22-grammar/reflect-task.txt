Есть CLI `mpu` в духе Smalltalk: строка — цепочка сообщений объектам. Голое слово — унарное сообщение (`kiten ls`), значение — только ключом (`kiten card id: 123`, ключи подряд — одно сообщение `id:text:`), `… end json` — формат результата. Каждый объект (корень, группа команд, команда, результат команды) понимает общий набор сообщений отражения — «расскажи о себе». Через них работает дополнение по Tab в оболочке и справка агенту.

Придумай имя (одно слово, латиница, как унарное или ключевое сообщение) для каждого вопроса, которое ты сам угадал бы с первой попытки, не читая справки:
1. Список всех сообщений, которые объект понимает (унарные и ключевые).
2. Понимает ли объект данное сообщение (да/нет).
3. Для команды: какие ключи есть у её ключевого сообщения (имя, обязательность, тип).
4. Для команды: какие ключи ещё можно добавить, если уже набраны `id:` (продолжение составного ключевого сообщения).
5. Какие форматы понимает результат команды (json, md, …).
6. Возможные значения для ключа (например, какие клиенты подходят под `target:` по началу «ром»).
7. Справка объекта.
8. Какие варианты (модификаторы до ключей, как `dry`, `all`) понимает команда.
9. Вызвать всё это для дополнения: одно сообщение «что можно написать здесь следующим словом» по уже набранным словам.

Ответ: таблица «№ → имя → как вызвать в строке (пример) → почему так». Затем: какие два-три имени тебе кажутся спорными и какое второе имя ты бы попробовал.
