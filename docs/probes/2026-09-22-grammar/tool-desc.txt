mpu — строка сообщений объектам mpu-back (Kaiten, SQL клиентов, логи, таблицы). Вход — массив слов `words`, как аргументы командной строки.

Грамматика (как в Smalltalk):
- Унарное сообщение — голое слово: `kiten ls`, `version`, `help`.
- Ключевое сообщение — `ключ: значение` или `--ключ значение`; ключи подряд — одно сообщение: `kiten card id: 123`, `sql-ro --target 54 --sql "select 1"`.
- Значение передаётся только ключом; голое слово — всегда сообщение, никогда не значение.
- Приоритет: унарное выше ключевого. Группа — `do … end`; сообщение после `end` уходит результату группы: `do kiten card id: 123 end md`.
- Порядок строки: варианты (унарные слова до первого ключа: `dry`, `all`, `local`) → ключи → формат результата (после `end`).
- Форматы результата: `json`, `md`, `csv`, `table` — какие понимает результат, говорит его `help`.
- Литерал `do`, `end`, `--`: через `--`: `text: -- end`.
- `target:` — где исполнить: номер клиента, имя или часть имени, `sl-N` (сервер), `dev:N` (клиент dev-стенда).
- Справка любого объекта — сообщение `help`: `kiten card help`, `help`.
- Строки, которые требуют подтверждения человека (запись, отправка), начинаются словом `ask`: `ask sql target: sl-1 sql: "…"`; без `ask` такая строка отказывает с подсказкой. Список таких строк — `ask help`.
