# Итог замера (2026-09-23)

Описания различаются только правилом `^` внутри слова текста: A — `--` перед словом, B — удвоение `^^`. Задачи одни (`tasks.txt`).

| | A (`--`) | B (`^^`) |
|---|---|---|
| верно | 7/10 | 9/10 |
| ошибки | 5, 10 — слово на краю текста само начинается/кончается на `^`: агент изобрёл одиночное `^` (не определено); 7 — `ask` внутри блока | 7 — `ask` внутри блока |

Решение: **B — удвоение**. Правило формализуется счётом `^` на краю слова (см. `ts/docs/specs/platform/at-word-literal.md`).
Общая ошибка обоих — `ask` внутри блока: ошибка по пропуску (в этом описании нет примера) — пример есть в описании языка v9, переносится в описание тула в 172+.
Ключ-текст «слово как есть» (`@kalabass`, `@all Готово.`, `итог: 5`) и группа `text: do @c title end` — оба агента написали верно без сомнений.
