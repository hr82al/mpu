mpu — Smalltalk на словах. Вход — слова: в MCP — массив `words` (один элемент — одно слово, пробелы внутри можно); в терминале — слова оболочки bash/fish/nu (кавычки оболочки склеивают слово; в файле программы кавычек нет).
- Голое слово — сообщение: `kiten ls`. Значение — только ключом: `ключ: значение`; значение ключа — РОВНО ОДНО слово.
- Порядок: команда → варианты → ключи → `end` → сообщения результату (`end json`, `end size`).
- Переменная: `x := kiten ls . x size`; в значении ключа — `@x` (`id: @c id`). Блок: `each: do :c … done`. Два выражения — через `.`.
- Ключи-текст (`text:`, `chat:`, `query:`) берут своё слово КАК ЕСТЬ: `@kalabass`, `@all Готово.`, `итог: 5`, `.` — просто текст. Переменную или выражение в ключ-текст — группой: `text: do @c title end`.
- Текст из нескольких слов без кавычек (терминал без кавычек, файл программы) — `^первое … последнее^`: слово на `^` в начале открывает, слово на `^` в конце закрывает; внутри ничего не толкуется (`end`, `:`, `@`, `.` — текст). `^` в середине слова (`x^2`) ничего не делает.
- Запись — строка начинается словом `ask`: `ask telegram send chat: me text: готово`, `ask kiten comment id: 5 text: ok`.
- Если слово ТЕКСТА само начинается или кончается на `^` — поставь `--` перед этим словом: `^ответ: -- 2^ готово^` даёт «ответ: 2^ готово».

Задачи. На каждую — массив слов JSON одной строкой (для «терминал» — слова так, как их получит mpu после оболочки, БЕЗ кавычек оболочки; для «MCP» — массив words).
1. MCP: отправить в Telegram в чат @kalabass текст «@kalabass Иван, итог: всё готово.»
2. Терминал без кавычек: то же.
3. Терминал без кавычек: себе (chat: me) текст «ответ: 2^ готово».
4. Терминал без кавычек: себе текст «формула x^2 верна».
5. Терминал без кавычек: себе текст «^_^ спасибо».
6. MCP: комментарий к карточке Kaiten 5 с текстом «@all готово. Проверьте».
7. MCP: для каждой моей карточки (`kiten ls`) отправить себе в Telegram её название (`@c title`).
8. Терминал без кавычек: себе текст «итог: 5 штук. end».
9. MCP: найти в Telegram сообщения по запросу «@ivan» (`telegram search query: …`).
10. Терминал без кавычек: себе текст «a^ и b^».
Затем «Где сомневался».
