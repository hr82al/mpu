Грамматика mpu (Smalltalk на словах; вход — массив слов `words`):
- Унарное — голое слово: `kiten ls`. Ключевое — `ключ: значение` или `--ключ значение`; ключи подряд — ОДНО сообщение (`id:text:`).
- Приоритет: унарное выше ключевого. Значение ключа — первичное (литерал или `@переменная`) плюс унарные сообщения ему: `id: @c id`. Литерал с унарным после — ошибка. Ключевой вызов внутри значения — только в группе.
- Непарный `end` закрывает выражение от начала строки; слово после `end` — сообщение результату: `kiten ls end json`.
- Литерал слова грамматики (`do`, `end`, `block`, `--`, слово на `@` или `:`) — через `--`: `text: -- end`. Кавычки литерала не делают.
- Запись (строка результата) отдаёт поле унарным сообщением: `@c id`, `@c title`, `@c column`.
- Коллекция: `size`, `first`, `where: <поле> is: <значение>`, `do: <блок>`, `collect: <блок>`, `select: <блок>`, `inject: <начальное> into: <блок с 2 параметрами>`.
- Числа и значения: `greater: n`, `less: n`, `equals: v` → булево; булево: `ifTrue: <блок> ifFalse: <блок>`; число: `timesRepeat: <блок>`, `+ n` нельзя — `plus: n`.
- Переменная: `@x`; присвоить — `x := <выражение>`; выражения в строке разделяет `.`.
- `print` — любой объект печатает себя (и возвращает себя).
- Метод навсегда в образе: `ask <получатель> define: <имя> <блок>`; имя без хвостового `:`, части через `:` (`cardsIn:since`), частей столько, сколько параметров у блока; без параметров — унарный метод.
- Строки с записью начинаются `ask`. `target:` — клиент по номеру/имени/части; `search query: <текст>` — клиенты; `sql-ro target: … sql: "…"` — SQL на чтение.

Блок: `block :a :b … end` — параметры `:имя` сразу после `block`, дальше тело. Группа, вычисляемая сразу, — `do … end` (не блок).
Пример: `kiten ls do: block :c @c id print end`; `kiten ls size greater: 10 ifTrue: block много print end ifFalse: block мало print end`.
