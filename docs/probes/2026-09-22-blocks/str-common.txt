Грамматика mpu (слова; одинаково в параметрах bash/fish/nu без кавычек и в файле программы, который делится по пробелам):
- Унарное — голое слово: `kiten ls`. Ключевое — `ключ: значение` или `--ключ значение`; ключи подряд — одно сообщение.
- Блок `do :x … end`; переменная `@x`; `x := …`; выражения через `.`; непарный `end` закрывает от начала строки, слово после — результату (`kiten ls end json`).
- Слово грамматики как литерал — через `--` перед ним: `text: -- end`.
- Кавычки ' и " не используются: оболочка их снимает. Символы ( ) [ ] { } < > | ; $ & # * ? писать нельзя.
- Комментарий: `rem <слова> end` — всё до `end` игнорируется; слово `end` внутри комментария — `-- end`.
- `kiten comment id: <номер> text: <текст>`; `kiten ls`; запись карточки: `@c id`, `@c title`, `@c column`; `where: <поле> is: <значение>`; `do:`/`collect:` у коллекций; `print`.
- Строки с записью начинаются словом `ask` (один раз, в начале всей строки или программы).
- Программа из файла: `mpu run: <файл> [<ключ>: <значение> …]`, параметры внутри — `@ключ`.
