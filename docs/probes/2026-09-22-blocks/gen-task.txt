CLI `mpu` — строка в духе Smalltalk, вход — массив слов (`words`), как аргументы оболочки. Уже есть:
- голое слово — унарное сообщение (`kiten ls`); значение — только ключом (`kiten card id: 123`), ключи подряд — одно сообщение; `--ключ значение` — то же, что `ключ: значение`;
- приоритет: унарное выше ключевого; группа, вычисляемая сразу, — `do … end` (непарный `end` закрывает от начала строки); после `end` — сообщение результату: `kiten ls end json`;
- значения ключей — литералы; слово грамматики как литерал — через `--`;
- результат-коллекция понимает `size`, `first`, `pick: <поле>`, `where: <поле> is: <значение>`;
- строки с записью начинаются словом `ask`: `ask kiten comment id: 55 text: ok`.
- `target:` — клиент/сервер по номеру, имени или части имени; `search query: <текст>` — найти клиентов.

Ограничение оболочек (bash, fish, nu): без кавычек нельзя использовать символы ( ) [ ] { } < > | ; $ & ' " и одиночное ~. Можно: буквы, цифры, @ % + , ^ / ! : . - _ = и слова.

Нужно добавить в язык: блоки (отложенный код с параметрами — замыкания), переменные (присвоить и сослаться), условия (как ifTrue:ifFalse: у объектов-булевых), циклы (do:/collect:/select: у коллекций, timesRepeat:), определение постоянного метода (сохраняется в образе). Всё — объекты и сообщения, как в Smalltalk.
