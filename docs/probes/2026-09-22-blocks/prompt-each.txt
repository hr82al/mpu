Грамматика mpu (слова; одинаково в параметрах bash/fish/nu без кавычек и в файле программы):
- Унарное — голое слово: `kiten ls`. Ключевое — `ключ: значение` или `--ключ значение`; ключи подряд — одно сообщение.
- Приоритет: унарное выше ключевого. Значение ключа — литерал или `@переменная` плюс унарные ей: `id: @c id`.
- Блок: `do :a :b … end` — параметры `:имя` сразу после `do`; `do … end` без параметров — и блок, и группа. Внутри блока неявной группы нет.
- Слово после `end` блока-аргумента — сообщение результату всего сообщения: `kiten ls collect: do :c @c id end print`.
- Переменная `@x`, присвоить `x := …`, выражения через `.`. Текст из нескольких слов — `^так вот^`. Комментарий — `rem … end`.
- Запись отдаёт поле унарным: `@c id`, `@c title`, `@c column`.
- Коллекция: `size`, `first`, `where: <поле> is: <значение>`, `each: <блок с 1 параметром>` (обойти), `collect:` (преобразовать), `select:` (отобрать), `inject: <нач> into: <блок с 2 параметрами>`.
- Числа: `greater:`, `less:`, `equals:`, `plus:`; булево: `ifTrue: <блок> ifFalse: <блок>`; `timesRepeat: <блок>`. `print` печатает.
- Запись начинается словом `ask` один раз в начале строки. `kiten comment id: … text: …`.
