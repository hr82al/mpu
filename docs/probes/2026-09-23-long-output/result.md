# Слепой замер: длинный вывод (sonnet, 2026-09-23)

Описание: tool-desc v5 + строка «Результат больше 64 КиБ тул целиком не отдаёт: пишет его в файл и отвечает путём, размером и подсказкой».

| Задача | Ответ |
|---|---|
| 20000 строк логов sl-1 за 6 ч | `logs portainer target: sl-1 since: 6h limit: 20000` — ключ `limit:` (не `tail:`); `portainer` — по примеру описания, лишний |
| сохранить логи в файл | без явного сообщения — расчёт на автосохранение |
| число строк без повтора | `it end size` |
| строки с ERROR | `it where: text includes: ERROR` |
| последние 50 | `it end last: 50` |
| `kiten ls` в файл json | `kiten ls end json` — явного «в файл» не придумал |

Вывод: `limit:` интуитивен; явное сообщение «в файл» агент не ищет — достаточно автоматического файла по порогу; пример `logs portainer` в описании уводит агента на Portainer — заменить пример варианта в следующей итерации описания (172+).
