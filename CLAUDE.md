# CLAUDE.md

Overview дерева `mpu` целиком. Корневой CLAUDE.md монорепо (`../CLAUDE.md`)
применяется как есть.

`mpu` (monorepo python utilities) — multi-purpose CLI для вспомогательных операций
над данными монорепо. Отдельный `.git` (этот каталог) — версионируется независимо
от `sl-back` / `sw-back` / `sw-front`. Ветки/MR не создавать, коммитить прямо в
`main` (как и `mp`; см. корневой Git & MR workflow).

## Структура

- `py/` — работающая реализация: весь функционал, которым пользуются сегодня
  (Python 3.12+, uv, typer, pytest, ruff, pyright strict). Специфика —
  `py/CLAUDE.md`.
- `ts/` — переезд на Deno/TS: **один бинарь**, две точки входа к одним и тем же
  командам — CLI для человека (`~/.local/bin/mpu`, `deno compile`) и MCP-сервер
  для агента (Streamable HTTP, Hono). Код пишется, не пустой каталог. Правила
  качества и тулинга модуля — `ts/CLAUDE.md`.
- Каталога `go/` больше нет (2026-08-04): спеки отменённой Go-редакции
  адаптированы под один бинарь и переехали в `ts/docs/specs/`, план — в
  `docs/plans/command-migration.md`, журнал — в `docs/migration-log.md`.
  `docs/go-migration.md` и `docs/broker-architecture.md` оставлены как история
  решений — не развивать.

## Переезд: где что лежит

- `docs/ts-mcp-architecture.md` — принятые архитектурные решения. Заменяет
  `broker-architecture.md`.
- `docs/plans/2026-08-03-ts-mcp-mvp.md` — план MVP: задачи, порядок, роли.
- `docs/migration-playbook.md` — процедура для оператора-человека.
- `docs/plans/command-migration.md` — план переезда команд: частоты, порядок,
  «не едут».
- `docs/migration-log.md` — журнал переезда: «умрёт вместе с Python», принятые
  расхождения сверок.

## Роли сессий

Переезд ведётся тремя ролями, и граница между ними — не формальность, а способ
не дать реализации подсмотреть в Python-код вместо спеки.

- **Спецификатор** — эта сессия (из `mpu`). Пишет **только** `ts/docs/`: спеки,
  golden-фикстуры, план. Кода в `ts/src/` не трогает.
- **Изолированная Deno-сессия** — пишет код `ts/`. Ей не видны ни `py/`, ни
  `docs/`, ни этот файл: знание о поведении Python-версии доходит до неё
  исключительно через `ts/docs/specs/` по правилам `ts/docs/CLAUDE.md`.
- **Оператор** — человек: запускает изолированные сессии и принимает результат.

Практическое следствие для этой сессии: внутри `ts/` менять можно `ts/docs/`;
исходники и тесты — читать, чтобы принять работу, но не править.

## Общее для всех реализаций

- `.env.example` — справочник переменных рантайм-конфига (`~/.config/mpu/.env`),
  не завязан на язык реализации.
- `.gitignore` — общий.
