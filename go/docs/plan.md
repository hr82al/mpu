# План переезда — команды по частоте использования

Скоуп по §1 правил переезда; состав секции «Не едут» решён 2026-07-27.
Источник частот: журнал вызовов mpu, 21–27.07.2026 (вся доступная
история — окно короче 6 месяцев), 3197 вызовов. Перед фиксацией списка
(§1.4) частоты пересобрать по свежему журналу — это уточнит порядок;
состав «Не едут» пересмотру не подлежит. Порядок списка — приоритет
ценности; порядок реализации иной: сначала обвязка, затем `xlsx` как
харнесс-команда (§4.4, утверждена), затем сверху вниз. Статус спеки
пишется рядом с пунктом (— / черновик / к реализации / реализовано);
сейчас у всех — «—».

⚠ Архитектурный поворот 2026-07-29: брокер — Go (удалённый сервис,
HTTPS + JSON-RPC 2.0, временный JWT; Python-делегация — у брокера),
CLI — Deno/TS (`ts/`). Детали — `mpu/docs/broker-architecture.md` (вне
`go/`, для сессии-спецификатора); там же решённая раскладка атомов
(брокер — секреты/внешние системы/enforcement/журнал; CLI — реестр/
справка/рендер/локальные команды) и каналы спек: `go/docs` — брокер +
протокол (`specs/protocol/`), `ts/docs` — CLI-спеки. Пересмотр спек
выполнен 2026-07-29: platform/registry — CLI-спека реестра
(маршрутизация + справка, включая бывшую CLI-часть dispatcher),
делегация Python выделена в platform/legacy-delegation (брокер);
снятые golden остаются эталоном CLI-поверхности.
Порядок «сначала обвязка, затем xlsx» сохраняется по смыслу; `xlsx` —
чисто локальная команда, первый вертикальный срез Deno-CLI без брокера.

## Обвязка (едет первой, `specs/platform/` + `specs/protocol/`)

- **protocol/core** — транспорт HTTPS + JSON-RPC 2.0, auth
  (login → временный JWT), формат ошибок, ядро операций
  (`auth.login`, `core.version`), enforcement `confirmed`.
  Сторона: контракт обеих сторон. Спека: к реализации (утверждена
  2026-07-29, повторно после оговорки о стриминге; учётки — хэш, TTL
  7 дней; контрактные пары — `fixtures/protocol/core/`).
- **protocol/legacy** — операция `legacy.run` + стриминговая форма
  ответа (NDJSON-кадры, keepalive, обрыв = SIGTERM). Сторона: контракт
  обеих сторон. Спека: к реализации (утверждена 2026-07-29; пары —
  `fixtures/protocol/legacy/`).

- **selector** — резолв `sl-N`/имени в сервер, PG-коннект и контейнеры.
  Сторона: брокер (CLI селектор не трактует). Спека: черновик
  (пересмотрена 2026-07-29).
- **config** — рантайм-конфиг. Расщеплён 2026-07-29: `.env` брокера
  (секреты/серверное) — `go/docs/specs/platform/config.md`; локальные
  предпочтения + `mpu config` — `ts/docs/specs/platform/config.md`
  (реестр: broker.url, sheet.default, xlsx.default; sheet.cache.* ушли
  в серверную политику). Обе спеки: черновик.
- **invoke-log** — журнал вызовов брокера: одна запись на операцию,
  формат записей оригинала сохранён (+ `user=`/`op=` вместо
  `pid=`/`cwd=`); `mpu log` — операции домена log (спека при переезде
  команды); локальные команды без брокера в журнал не попадают.
  Сторона: брокер. Спека: черновик (пересобрана 2026-07-29).
- **readonly-default** — чтение по умолчанию, мутация — с подтверждением.
  Сторона: enforcement — брокер (read-only PG-сессия + `confirmed` в
  операции), интерактив — CLI. Спека: черновик (пересмотрена
  2026-07-29).
- **legacy-delegation** (бывш. dispatcher) — операция исполнения
  не переехавших команд Python-mpu рядом с брокером. Сторона: брокер.
  Спека: к реализации (2026-07-29, вместе с protocol/legacy).
- **registry** — реестр команд Deno-CLI: маршрутизация (включая
  legacy-fallback) + `help`/`version`/completion. Сторона: CLI.
  Спека: к реализации — `ts/docs/specs/platform/registry.md`
  (2026-07-29; golden сняты; справка legacy-команд приходит
  делегацией).

## Команды к переезду (по частоте)
