# mpu

CLI для вспомогательных операций над монорепо: данные клиентов, состояние
сервисов, внешние таблицы, интеграции. Один бинарь и две точки входа к одним и
тем же командам — терминал для человека и MCP-сервер для агента.

Дерево, план и роли сессий — `CLAUDE.md`. Контракты команд —
`ts/docs/specs/`.

## Первичная установка

Нужен [Deno](https://deno.com) ветки 2.x (разрабатывается и проверяется на
2.9.x) и `~/.local/bin` в `PATH`.

```
cd ts && deno task build
mpu version
```

Задача собирает бинарь и кладёт его в `~/.local/bin/mpu`. Этот путь нужен один
раз: дальше инструмент обновляет себя сам.

Реквизиты подключений живут в `~/.config/mpu/.env`; какие ключи бывают и что
каждый значит — `.env.example`, он же шаблон. Кэш и журнал вызовов заводятся при
первом запуске в `~/.config/mpu/`.

## Обновление

```
mpu build           пересобрать из исходников и переустановить
mpu build --check   собрать и проверить, установку не трогать
```

Установка атомарна: пока свежесобранное не прошло проверку, установленное не
меняется; не ответило после замены — возвращается прежнее. Работающая служба
MCP перезапускается сама, иначе в памяти осталась бы прежняя версия.

Исходники команда ищет двумя способами — рядом с работающей программой и по
сентинелу рабочей области `.mp-workspace-root`; ни один не подошёл — отказ
называет оба проверенных места. Подробности — `ts/docs/specs/build.md`.

## MCP-сервер

Разово, в переднем плане:

```
mpu mcp                      слушает 127.0.0.1:7337, профили /ro и /rw
mpu mcp token                заголовок авторизации для клиента
```

Постоянно, службой пользователя (`systemd --user`):

```
mpu mcp enable     описать службу, запустить, включить в автозапуск
mpu mcp status     состояние, адрес, версия, автозапуск
mpu mcp restart    перезапустить
mpu mcp stop       остановить, не снимая с автозапуска
mpu mcp disable    остановить, снять с автозапуска, удалить описание
```

Служба живёт вместе с сеансом пользователя: после выхода из системы она
остановится, пока не включена задержка (`loginctl enable-linger`). `status` об
этом говорит.

Голое `mpu mcp` при поднятой службе уступает ей порт: останавливает её,
работает в переднем плане и запускает обратно, когда закончит. Прерывание с
клавиатуры это переживает, снятие процесса без обработки — нет; тогда служба
остаётся остановленной, `status` покажет, `start` вернёт.

## Разработка

```
deno task test      проверки
deno task smoke     проверка собранного бинаря: права, зашитые при сборке
```

`deno task test` идёт с широкими правами и нехватку `--allow-*` в задаче сборки
не видит — её ловит только запуск самого бинаря, то есть `smoke`.
