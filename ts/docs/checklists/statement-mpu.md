# Чек-лист постановки — специфика `mpu`

Применяется ПОСЛЕ универсального `statement.md` к той же постановке.

1. **Строка и её итог.** Каждый сценарий команды — полная строка вызова и
   полный наблюдаемый итог: stdout дословно (включая то, чем он оканчивается),
   stderr, код выхода. Ключи — в обоих написаниях (`seller-id: 5` и
   `--seller-id 5`), если команда их принимает.
2. **Справка — сценарий, а не оформление.** Есть сценарий `--help` / `help`:
   однострока называет вопрос, на который команда отвечает; первый абзац —
   момент, когда её зовут, и чем она лучше подручного средства
   (`docs/specs/platform/registry.md`, «Что говорит справка»).
3. **Видимость агенту.** Сценарий «агент видит / не видит команду» и сценарий
   решения политики (выполнить / спросить / отказать) — для каждой новой
   команды. Молчание здесь — решение «не видна», принимать его осознанно
   (`docs/specs/fixtures/mcp-server/tool-policies.json`, список fail-closed).
4. **Пишущая команда.** Сценарии даны на локальном стеке; сценарий отказа без
   подтверждения. Прод в сценариях не фигурирует никогда (`ts/CLAUDE.md`,
   «Прод не меняем ничем и никогда»).
5. **Секрет не появляется.** Сценарий ошибки рядом с секретом: токен и пароли
   не видны ни в выводе, ни в тексте ошибки (`ts/CLAUDE.md`, «Секреты»).
6. **Тишина различима.** Если успех выглядит как отсутствие вывода — сценарий,
   где шаг не исполнился, и его наблюдаемое отличие от успеха (`ts/CLAUDE.md`,
   «Отсутствие признака — не наблюдение»).
7. **Стык — снятым образцом.** Ответ чужой службы в сценарии — литерал, снятый
   живьём, с источником; сочинённый ответ помечается как догадка
   (`ts/CLAUDE.md`, «Фикстуру стыка снимают, а не сочиняют»).

## Анти-примеры

- Порция 93: пометка `(required)` в описании поля появилась рядом с
  «(обязателен)», выведенным из схемы, — постановка назвала факт словами там,
  где его уже называла машина.
- 2026-08-28: сценарий записи в таблицу опирался на поле `totalUpdatedCells`,
  которого служба не отдаёт; живой ответ — `{"value": "data batchUpdate succesfull"}`.
