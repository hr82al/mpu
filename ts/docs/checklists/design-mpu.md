# Чек-лист проектирования — специфика `mpu`

Применяется ПОСЛЕ универсального `design.md`. Артефакт каждого пункта — строка в
разделе «Пункты чек-листа» спеки: что изменил, или «ничего».

1. **Команда — сообщение объекту.** Новая команда — метод получателя, который
   сам отвечает на исполнение, справку и дополнение. Центральный реестр со
   `switch` по имени команды или таблица «имя → функция + флаги» — находка.
   Артефакт: получатель и его сообщения.
2. **Вид метода — реализация, не флаг.** «Возвращает объект / данные»,
   «пишущая / читающая», «виден / не виден агенту» — разные реализации
   протокола или решение владельца политики, не булево поле рядом с телом.
   Артефакт: список таких признаков → чем выражены.
3. **Решение политики — у её владельца.** Отсутствие правила — один
   null-объект «наследуемое правило»; свёртка цепочки («самое строгое») —
   метод объекта-решения, не свободная функция над списком строк.
4. **Один факт — один источник.** Для обязательности, типа, значения по
   умолчанию и кода выхода назван единственный источник; справка, строка
   использования и схема тула выводятся из него (`ts/CLAUDE.md`, «У одного
   факта один источник»).
5. **Величина — из результата работы.** У каждого печатаемого числа назван
   результат действия, из которого оно берётся; одно число на два действия —
   находка (`ts/CLAUDE.md`, «Величина берётся там, где совершается работа»).
6. **Права Deno.** Новое право — отдельной строкой с обоснованием; назван
   тест, который краснеет от его снятия (`ts/CLAUDE.md`, «Права Deno»).
7. **Границы модулей.** Поверхность — `mod.ts`; модуль назван предметной
   областью; `main.ts` — только склейка (`ts/CLAUDE.md`, «Границы модулей»).
8. **Внешнее — переданной ссылкой.** Часы, окружение, файловая система, сеть,
   tty — параметры получателя, не импорт и не `Deno.env` по месту.
9. **Голден — снятый.** У каждой фикстуры стыка назван источник снятия; где
   снять нельзя — пометка «догадка» и кто проверит.
10. **Пропускаемая проверка.** Если проверка умеет пропускаться — спека
    требует два предъявленных прогона: исполнившийся и покрасневший, и
    дословную причину пропуска.

## Анти-примеры

- 2026-08-17 (`telegram search`): правка закрытого списка публикации без
  пересборки снапшотов дала реализующей сессии красные гейты на чужой правке.
- 2026-08-31 (`d2-miro`): вывод `shapes=0 skipped=10` при коде выхода 0 —
  числа говорили правду, код нет; два источника одного факта.
- 2026-08-31 (`api`): эталон хранил имя и тип поля, но не обязательность —
  у 23 команд признак потерян при рабочем механизме отказа.
