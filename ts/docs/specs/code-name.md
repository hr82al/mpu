# mpu code name

Статус: к реализации (2026-09-08; голдены — `fixtures/code/`)

## Назначение

Не занято ли это имя другим смыслом. Вопрос задают перед тем, как внести
объявление: два тёзки с одинаковым типом возврата и разной семантикой не
спросит ни компилятор, ни читатель.

Команда перечисляет объявления с сигнатурами и не описывает их прозой:
описание расходится с кодом молча, в отличие от сигнатуры.

## CLI-контракт

`mpu code name ИМЯ [--in ОКНО] [--limit N]`

Политика — `ro`. Объявление и форма вывода —
`platform/command-contract.md`; общий слой — `platform/code-analyzer.md`.

**ИМЯ** — точное имя объявления, без подстановочных знаков.

**`--in ОКНО`** — `РЕПОЗИТОРИЙ` целиком либо `РЕПОЗИТОРИЙ:КАТАЛОГ`.
Окно уровня каталога обязательно: занятость имени решают объявления там,
куда вносят новое, а не во всём репозитории. Не задано — ответ по
**каждому** репозиторию рабочей области, своим разделом со своей
отметкой дерева; разделы не смешиваются даже при совпадении имён.

**`--limit N`** — предел строк в каждом разделе, по умолчанию 200.

Справка листовой команды:

    mpu code name ИМЯ [--in ОКНО] [--limit N]

    Все объявления этого имени с сигнатурами и адресами: занято ли имя
    и в каком смысле. Отдельной строкой — типы возврата; если их больше
    одного, сказано, что они различаются.

    Имя встречается один раз или не встречается вовсе — пустой ответ, а
    не отказ.

    Без --in отвечает по каждому репозиторию рабочей области отдельным
    разделом.

      --in ОКНО   РЕПОЗИТОРИЙ или РЕПОЗИТОРИЙ:КАТАЛОГ — обычно каталог
                  пакета, а не весь репозиторий
      --limit N   предел строк в разделе (по умолчанию 200)

## Ввод/вывод

Шапка и раздел «не разрешено» — `platform/code-analyzer.md`. Свои
разделы:

**объявления: N** — по две строки на объявление:

- `путь:строка  ИМЯ (параметры): тип` — сигнатура как объявлена;
- отступом ниже — область видимости: `экспортируется из модуля и из
  входа проекта`, `экспортируется из модуля; из входа проекта не
  реэкспортируется` либо `приватное в модуле`.

Форма объявления на попадание в перечень не влияет: `function`, стрелка
в `const`, метод. Текстовый поиск по `function ИМЯ` пропускает стрелки,
и это одна из причин заводить команду.

**типы возврата: …** — перечень уникальных типов возврата через запятую.
Их больше одного — строка оканчивается ` — различаются`. Строка
печатается всегда, когда объявлений хотя бы два.

Нулевой раздел печатается как `объявления: 0` без последующих строк:
это ответ «имя свободно», а не отказ.

## Инварианты

- В перечень попадают объявления любой формы: `function`, стрелка,
  метод.
- Область видимости названа у каждого объявления.
- Строка типов возврата печатается при двух и более объявлениях и
  помечает расхождение явно.
- Пустой перечень — ответ (exit 0), не отказ.
- Без `--in` каждый репозиторий отвечает своим разделом со своей
  отметкой; объединённого перечня не бывает.
- Порядок строк — `(репозиторий, путь, строка)`.
- Команда только читает.

## Граничные случаи и ошибки

Ошибки — stderr с префиксом `mpu code name: `.

| Вход | Ожидаемое поведение |
| --- | --- |
| Имя пустое | exit 2, `нужно имя объявления` |
| Репозиторий окна неизвестен | exit 2, `неизвестный репозиторий '<имя>'`, следом перечень известных |
| Каталог окна не существует | exit 2, `каталога '<путь>' нет в <репозиторий> на <отметка>` |
| Имя не встречается | exit 0, `объявления: 0` |
| Имя встречается один раз | exit 0, перечень из одного; строка типов возврата не печатается |
| Тёзки в разных репозиториях | два раздела, каждый со своей отметкой; объединения нет |
| Тёзки с разными типами возврата | строка типов возврата оканчивается ` — различаются` |
| Раздел длиннее `--limit` | exit 0, строка `усечено: показано N из M` |

## Golden-примеры

`fixtures/code/`. Дерево-фикстура — `platform/code-analyzer.md`. Каждый
файл оканчивается одним переводом строки.

- `name-collision.stdout.txt` — `name spanDays --in fixture`: два
  объявления одного имени с одинаковым типом возврата и разной
  семантикой. Одно объявлено `function` и экспортировано, другое —
  стрелкой и приватное. Тест обязан краснеть, если перечень начнёт
  собираться только по `function`: останется одно объявление из двух.
- `name-empty.stdout.txt` — `name nothingHere --in fixture`: имя
  свободно. Ответ, а не отказ: `объявления: 0`, exit 0, строки типов
  возврата нет.
