# mpu sheet

Статус: реализовано (заморожена 2026-08-27; формы `ls`/`get`/`resolve`,
флаг `fromCache` и тексты отказов сняты живьём с рабочей версии;
реализация проверена тестами и голденами, живой прогон — за сессией,
которой видны webapp и рабочая версия)

## Назначение

Чтение Google-таблиц через Apps Script webapp с whole-tab кэшом:
значения диапазонов (`get`), список листов (`ls`), диагностика резолва
цели (`resolve`). Транспорт, retry, кэш и резолв цели — атом
`platform/webapp-http.md`; здесь — только CLI-поведение трёх подкоманд.
Остальные подкоманды семейства (`set`, `open`, `alias`, `sync`,
`cache`) — отдельные спеки, не эта; пара `batch-update`/`batch-get`
специфицируется единой спекой `sheet-batch.md`.

## CLI-контракт

`mpu sheet` без подкоманды печатает справку, exit 2. Резолв
цели-spreadsheet (общий для трёх подкоманд): `-s/--spreadsheet` → env
`MPU_SS` → конфиг `sheet.default`; значение — URL, ID, алиас,
client_id или подстрока заголовка (правила и тексты ошибок — атом).

`mpu sheet get [RANGES...] [-s SS] [-n/--sheet TAB] [--from FILE|-]
[--render both|values|formulas|formatted] [--raw] [--tsv]
[-R/--refresh]`
- Источники диапазонов складываются: аргументы + `--from` (построчно,
  `-` = stdin; пустые строки и строки, начинающиеся с `#` после trim,
  пропускаются).
- `--sheet TAB` префиксует диапазоны без `!` (`TAB!A1:B2`, имя
  кавычится по правилам A1); диапазоны с `!` не трогаются. Нет ни
  аргументов, ни `--from`, но задан `--sheet` → читается весь лист TAB.
- Совсем нет диапазонов → stderr
  `Usage: mpu sheet get [RANGES...] [--from FILE] [--sheet TAB]`,
  exit 2.
- `--render` вне четырёх значений → stderr
  `--render must be one of: both, values, formulas, formatted`, exit 2
  (до обращения к БД и сети). Дефолт `both` — значения и формулы;
  `values`/`formulas` — один слой; `formatted` — отформатированные
  строки (locale таблицы), всегда мимо кэша.
- `--raw` вместе с `--tsv` ошибкой **не** является: действует `--tsv`,
  вывод байт в байт равен вызову с одним `--tsv`, exit 0 (снято живьём
  2026-08-27; прежняя редакция спеки обещала здесь отказ — обещание
  было неверным).
- `-R/--refresh` — не читать кэш (листов и метаданных), перечитать из
  webapp, перезаписать кэш.
- Вывод по умолчанию — JSON
  `{"spreadsheetId": "<ss_id>", "valueRanges": […]}`, элемент —
  `{"range": …, "values"?: [[…]], "formulas"?: [[…]],
  "formatted"?: [[…]], "fromCache": bool}`; слои присутствуют ⇔
  запрошены `--render`; indent=2, ensure_ascii=false, финальный `\n`.
  `range` при чтении через кэш — нормализованная закрытая форма по
  фактическим границам листа; при прямом чтении (formatted, большой
  лист) — адрес из ответа webapp.
- `--raw`: берётся один слой приоритетом values → formulas → formatted;
  ячейки строки́ через `\t`, строки через `\n`; ровно один диапазон,
  давший ровно одну строку без `\t` внутри, → без финального `\n`,
  иначе финальный `\n`.
- `--tsv`: те же строки, диапазоны разделяются пустой строкой, всегда
  финальный `\n`.
- Рендер ячеек в raw/tsv — строковый: пустая ячейка → пустая строка,
  bool → `True`/`False`, числа → `42`/`3.5` (см. «Известные
  отклонения»).

`mpu sheet ls [-s SS] [-l/--long] [--json] [-R/--refresh]`
- default: `{title}\n` на лист, порядок — как в таблице;
- `-l`: `{title}\t{rows}×{cols}\tsheetId={sheetId}\tindex={index}`;
- `--json`: массив `{"title", "sheet_id", "rows", "cols", "index"}`,
  indent=2, ensure_ascii=false, финальный `\n`;
- `-l` вместе с `--json` ошибкой **не** является: действует `--json`,
  вывод байт в байт равен вызову с одним `--json`, exit 0 (снято живьём
  2026-08-27; прежняя редакция обещала здесь отказ — обещание было
  неверным);
- `-R` — мимо кэша метаданных, с перезаписью.

`mpu sheet resolve [-s SS]`
- Только резолв цели, без сети. stdout — JSON `{"ss_id", "source":
  "flag"|"env"|"config", "kind":
  "url"|"id"|"alias"|"client_id"|"title_fuzzy", "original_input"}`,
  indent=2, ensure_ascii=false, финальный `\n`; exit 0.

## Ввод/вывод

stdout — данные; stderr — ошибки без трейсбеков. Ошибка «несколько
кандидатов» печатается полным многострочным текстом из атома; прочие —
одной строкой `mpu sheet: <текст>`. Exit: 0 — успех; 2 — ошибки ввода
и резолва цели; 1 — ошибки webapp/сети и «лист не найден».

## Побочные эффекты

Сеть (`get`, `ls`) — POST на webapp (атом); `resolve` — без сети.
Кэш-БД: housekeeping перед каждой подкомандой + чтение/запись кэша
листов и метаданных (атом). `--from` читает файл или stdin. Google-
таблицу ни одна из трёх подкоманд не изменяет.

## Конфигурация

env `WB_PLUS_WEB_APP_URL` (нужен `get`/`ls`), `MPU_SS`; конфиг-ключи
`sheet.default`, `sheet.cache.*` — атом `platform/webapp-http.md` и
`platform/config.md`.

## Инварианты

- Ни одна из подкоманд не пишет в Google-таблицу; единственная
  локальная мутация — кэш-БД (housekeeping и запись кэша).
- `resolve` не ходит в сеть; повторный вызов при неизменном окружении
  и кэш-БД даёт побитово тот же вывод.
- Повторный `get` того же диапазона при живом кэше отвечает
  `"fromCache": true` без сетевых обращений за данными листа.
- Ключ слоя (`values`/`formulas`/`formatted`) присутствует в JSON ⇔
  слой запрошен `--render`.
- Валидация `--render`, конфликта флагов и пустого набора диапазонов —
  до обращения к БД и сети.
- Порядок `valueRanges` повторяет порядок входных диапазонов.

## Граничные случаи и ошибки

- Цель не задана ни одним источником → stderr `mpu sheet: Spreadsheet
  не указан. …` (текст — атом), exit 2.
- Несколько кандидатов резолва → полный текст «Несколько
  spreadsheet'ов матчат …», exit 2.
- `WB_PLUS_WEB_APP_URL` не задан → `mpu sheet: WB_PLUS_WEB_APP_URL не
  задан. Добавь в <путь env-файла> или export в shell.`, exit 1.
- Лист не найден в таблице → stderr `mpu sheet: лист '<имя>' не найден
  в spreadsheet <ss_id>; доступные: <имена через запятую+пробел>`,
  exit 1 (fix, см. «Известные отклонения»).
- Диапазон без имени листа при незаданном `--sheet` (`A1:B2`) → stderr
  `mpu sheet: диапазон '<строка>' без имени листа; попробуй: --sheet
  TAB или префикс 'Лист!'`, exit 2 (fix).
- Невалидный A1-диапазон (`Лист!`, `Лист!A1:`, пустая строка) → stderr
  `mpu sheet: невалидный диапазон '<строка>'`, exit 2 (fix).
- `--from` с несуществующим файлом → stderr `mpu sheet: файл
  '<путь>' не найден`, exit 2 (fix).
- Диапазон в пределах листа, но без данных (чтение через кэш) → слой
  прямоугольником из `""`; при прямом чтении — `[]` (как в ответе
  webapp); диапазон целиком за фактическими границами листа → слой
  `[]`; exit 0 (не ошибка).
- Ошибка webapp (5xx/429/квота после исчерпания бюджета попыток,
  ложный `success`) → `mpu sheet: <текст ошибки из атома>`, exit 1.

## Golden-примеры

Сняты 2026-08-27 с рабочей версии на служебной тестовой таблице (лист
`Sheet1`, содержимое `A1="привет"`, `B1=42`, `B2==B1*2`); идентификатор
таблицы в фикстурах заменён синтетическим, клиентских данных нет.

- `fixtures/sheet/resolve.stdout` — `resolve -s <id>`, без сети;
- `fixtures/sheet/ls-long.stdout` — `ls -l`;
- `fixtures/sheet/ls-json.stdout` — `ls --json`;
- `fixtures/sheet/ls-long-json.stdout` — `ls -l --json`: побеждает
  `--json`, файл совпадает с предыдущим;
- `fixtures/sheet/get-both-cached.stdout` — `get 'Sheet1!A1:B2'` при
  живом кэше (`"fromCache": true`); первый вызов той же формы с `-R`
  отличается только значением этого поля;
- `fixtures/sheet/get-raw.stdout` — тот же диапазон с `--raw`;
- `fixtures/sheet/get-tsv.stdout` — с `--tsv`; вызов `--raw --tsv`
  даёт этот же файл;
- `fixtures/sheet/err-no-ranges.stderr` — `get` без диапазонов, exit 2.

Случаи с вердиктом fix (лист не найден, невалидный диапазон, `--from`
без файла) с живой версии не снимаются — там поведение отклонения;
эталон задаёт текст этой спеки.

## Известные отклонения

- **fix** — лист, отсутствующий в таблице, роняет `get` многострочным
  трейсбеком (перехватываются только ошибки webapp); правильное
  поведение — одна строка stderr с перечнем доступных листов, exit 1.
- **fix** — невалидный A1-диапазон и диапазон без имени листа при
  незаданном `--sheet` падают трейсбеком; правильное — ошибка ввода
  одной строкой, exit 2.
- **fix** — `--sheet` с именем листа, похожим на ссылку-ячейку (`ABC`,
  `B2`), без диапазонов падает трейсбеком вместо чтения всего листа;
  правильное — весь лист, как для любого другого имени.
- **fix** — `--from` с несуществующим файлом падает трейсбеком;
  правильное — ошибка ввода, exit 2.
- **preserve** — raw/tsv печатают bool как `True`/`False`. Причина:
  единообразие с `mpu xlsx` (там preserve ради пустого differential);
  идея унификации — в журнал переезда.
