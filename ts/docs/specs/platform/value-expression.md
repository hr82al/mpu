# Выражение на месте значения; `stdin`

Статус: к реализации — порция 161.

## Назначение

На месте значения ключа может стоять группа `do … end`: её результат —
значение. Так команды сочетаются без оболочки и без копирования руками. Тем
же правилом «что стоит на месте значения» `stdin` становится первичным
выражением вместо шести неявных подстановок.

## Правила

| Запись | Итог |
|---|---|
| `ключ: do <выражение> end` | выражение вычисляется до ключевого сообщения; его результат — значение ключа [D.1] |
| результат — скаляр (текст, число, булево) | значение — его текстовый вид |
| результат — данные не-скаляр (список, запись) | отказ `<путь>: значение ключа <ключ> — не скаляр (<вид>); выбери поле` с готовой строкой, если у результата одно поле; код 2; ничего не исполнено |
| результат группы — отказ или код ≠ 0 | строка отказывает тем же текстом и кодом; внешнее сообщение не исполняется |
| группа внутри группы значения | допустима |
| `do` на месте значения | открывает группу (в 158 — отказ «только в начале строки») |
| `ключ: stdin` | значение — stdin целиком (текст, хвостовой перевод строки снят) [D.2] |
| `stdin` дважды в строке | отказ «stdin уже прочитан ключом <ключ>», код 2, до исполнения |
| stdin — терминал | как у нынешних подстановок: `sql` — чтение до Ctrl+D; прочие — отказ «stdin — терминал» |

Прежние неявные подстановки (значение не дано, литерал `-`, `--from -`,
`--body-file -`) работают как сейчас — `stdin` их не снимает в этой порции;
справки называют `stdin` основным способом.

## Правила подтверждения

- Группа значения — отдельная строка для правил: её путь решается сам; внешнее
  сообщение — своим путём. `ask` в начале строки объявляет запись для всей
  строки (`ask-door.md`); группа-чтение вопроса не задаёт.
- Если внутренняя группа — запись (`ask`-путь), а строка без `ask` — адресный
  отказ до исполнения чего-либо.

## Инварианты

- Внешнее сообщение исполняется только после успешного вычисления всех групп
  значений.
- Группа значения исполняется ровно один раз.
- `stdin` читается ровно один раз за строку.

## Граничные случаи

| Строка | Ожидается |
|---|---|
| `mpu ask kiten comment id: 1 text: do jsdate end` | вопрос с текстом строки, где значение уже вычислено; затем комментарий с меткой времени |
| `mpu kiten comment id: 1 text: do kiten ls end` | отказ «значение ключа text — не скаляр (список)», ничего не исполнено |
| `mpu kiten comment id: do nope end text: x` | отказ `mpu nope: не понимает …` из группы, код 2 |
| `echo "select 1" \| mpu sql-ro target: 54 sql: stdin` | как прежде `echo … \| mpu sql-ro target: 54` |
| `mpu sql-ro target: 54 sql: stdin` из терминала | чтение до Ctrl+D, как прежде |
| `mpu kiten comment id: 1 text: stdin` из терминала | отказ «stdin — терминал», код 2 |
| `… text: stdin … note: stdin` | отказ «stdin уже прочитан ключом text» |
| `mpu kiten comment id: 1 text: -- stdin` | значение — слово `stdin` |
| `mpu kiten card id: do jsdate end end json` | результат группы — значение, `end json` — формат внешнего результата |

  не-скаляр в значении — отказ.
