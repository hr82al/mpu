# Слово на `@`, `^` и `.` в значении — литерал, если это не имя

Статус: к реализации — порция 167b (после 168).

## Назначение

Живьём 2026-09-23 16:15 (сессия агента, MCP): `["ask", "telegram", "send",
"md", "chat:", "-1003949382772", "text:", "@kalabass Иван, @EugenePasternak
Евгений, добрый вечер. Посмотрите пожалуйста MR\n\n[!675 — …](https://gitlab.btlz-api.ru/…)"]`
→ `выражение 1: поле — унарным: @kalabass Иван, … вечер  Посмотрите …
gitlab btlz-api ru …`, код 2, без готовой строки. Разбор 166 считает
переменной **любое** слово, начинающееся на `@`, а точки в нём — доступом к
полю. Текст сообщения, начатый упоминанием, в MCP не отправить; то же у
Kaiten (`@all Готово`). Замер хоста: `text: .` (значение — точка) разбирается
как разделитель выражений, и `help` после него отказывает «строка может
записать (help)».

## Правила

Слово значения ключа толкуется по форме **всего слова**:

| Слово | Толкование |
|---|---|
| `@имя` (имя — буквы, цифры, `_`, `-`; первая — буква или `_`) | переменная (166); несвязанная — прежний отказ с «текстом — `-- @имя`» и `hint` |
| `@имя.имя…` (только имена через `.`) | прежний отказ «поле — унарным: `@c title`» и `hint`: `-- @c.title` (текстом) |
| прочее, начинающееся на `@` (пробел, перевод строки, `,`, `:`, `/` и т. п.) | литерал как есть |
| `^…^` одним словом (MCP, кавычки оболочки) | текст без `^` по краям |
| прочее, начинающееся на `^` и не кончающееся на `^`, с пробельным символом внутри | литерал как есть |
| `.` значением ключа (слово сразу после ключа) | литерал `.` |

Правило одно для CLI и MCP; в CLI слово с пробелом приходит из кавычек
оболочки. Разбор выражений и отказы 166 для слов-имён не меняются.

Справка `telegram send` и соседей, где `chat:` — `@username`: пример — `chat:
-- @username`; упоминание в начале текста — одним словом (MCP, кавычки) без
`--`.

Отдельно: корневое `help` отдельным выражением (`… . help`) — справка корня,
решение правил `allow` (обход 167 не считает его записью).

## Граничные случаи

| Строка (MCP words) | Ожидается |
|---|---|
| `["telegram","send","chat:","me","text:","@ivan привет. Посмотри MR https://x.y/z"]` | текст уходит как есть (стенд), код 0 |
| `["kiten","comment","id:","1","text:","@all Готово. Проверьте"]` | текст как есть (стенд) |
| `["telegram","send","chat:","@ser_dantes_r","text:","привет"]` | «ser_dantes_r не связана; …; текстом — -- @ser_dantes_r», код 2, `hint` с `--` |
| `["x",":=","1",".","kiten","card","id:","@x"]` | переменная, как в 166 |
| `["kiten","card","id:","@c.title"]` | «поле — унарным», `hint` с `-- @c.title` |
| `["telegram","send","chat:","me","text:","."]` | текст `.` |
| `["telegram","send","chat:","me","text:","^привет^"]` | текст `привет` |
| `["2","print",".","help"]` | `2`, затем справка корня, код 0 |
| CLI `mpu telegram send chat: me text: "@ivan привет. ok"` | как MCP |

Проверка «текст уходит» — на подменённом Telegram/Kaiten, не в прод.
