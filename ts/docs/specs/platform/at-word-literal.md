# Значение ключа берётся как есть

Статус: порция 167b (`28c29cb`, `c3c449d`) принята 2026-09-23; тексты `^…^`, переменные и блоки снимаются порцией L1 (`stage6-l1.md`) — остаётся общее правило: значение любого ключа берётся как есть.

## Назначение

Живьём 2026-09-23 16:15 (сессия агента, MCP): `["ask", "telegram", "send",
"md", "chat:", "-1003949382772", "text:", "@kalabass Иван, @EugenePasternak
Евгений, добрый вечер. Посмотрите пожалуйста MR\n\n[!675 — …](https://gitlab.btlz-api.ru/…)"]`
→ отказ «поле — унарным»: разбор считал переменной любое слово на `@`. Текст,
начатый упоминанием, в MCP не отправить; `chat: @kalabass` — тоже.

Решение: граница значения не угадывается, слово ключа не толкуется.

## Правило. Значение ключа — одно слово, как есть

- Значение ключа — ровно одно слово: элемент массива MCP или слово оболочки
  (кавычки оболочки склеивают). Дальше значение не продолжается.
- Слово не толкуется ни у какого ключа: `@kalabass`, `@all Готово.`, `^_^`,
  `итог: 5`, `.`, `end` — значение как есть. `chat: @username`,
  `text: ^_^`, `text: @ivan` — значение, не форма строки.
- Исключения: `do` открывает группу значения (текст «do» — `-- do`); слово-ключ
  этой команды (`text: chat: me`) — отказ «у ключа text нет значения»; блок
  `do :x` отказывает «не команда mpu» и на месте значения ключа.
- `--` перед значением — экранирование, как везде: `text: -- end` → «end».
- `stdin` значением ключа — ввод строки (как в 161): `text: stdin`.
- Флаги `--x`, `--x=v`, `--help` значения не берут — следующее слово стоит на
  месте слова строки; значение берёт только `имя:`.

## Граничные случаи

| Строка (MCP words / терминал) | Ожидается |
|---|---|
| MCP `["telegram","send","chat:","@kalabass","text:","@kalabass Иван, итог: всё готово."]` | адресат `@kalabass`, текст как есть (подменённый Telegram) |
| `telegram send chat: @username text: ^_^` | адресат `@username`, текст `^_^` (стенд) |
| MCP `["kiten","comment","id:","5","text:","@all готово. Проверьте"]` | текст как есть (стенд) |
| `… text: ^итог: 5 штук. end^` | слово `^итог:` — значение как есть; `5` — слово на месте слова строки, отказ команды |
| `… text: .` | текст «.» |
| MCP `["telegram","search","query:","@ivan"]` | запрос «@ivan» |
| `kiten card id: @c.title` | значение `@c.title` дошло до команды как есть (отказ типа `id`), не отказ грамматики |
| `@x print`, `^привет мир^ print` | отказ «не команда mpu» (`stage6-l1.md`) |

Проверка «текст уходит» — подменённым Telegram/Kaiten, не в прод.
