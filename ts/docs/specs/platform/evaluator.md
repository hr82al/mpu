# Вычислитель строки: выражения, переменные, блоки, базовые объекты

Статус: к реализации — порция 166 (после 166a: строку исполняет процесс-исполнитель).

## Назначение

Строка `mpu` становится программой на маленьком Smalltalk: несколько выражений,
переменные, блоки-замыкания, условия и циклы — сообщения объектам. Синтаксис
выбран слепыми замерами `sonnet` (описание v9 — 9/10). Однокомандная строка
серии 158–165 ведёт себя побайтово как прежде.

## Слова грамматики

Константа модуля разбора (`line-grammar.md`, [D.1]) пополняется: `done`
(конец блока), `rem` (комментарий), `.` (разделитель выражений — отдельное
слово), `:=` (присваивание), знаки `^` (текст), `@` (переменная в значении),
`:` в начале слова после `do` (параметр блока). Литералом в коде и тестах они
не пишутся нигде, кроме константы; мутация «другое слово в константе» меняет
разбор, справку корня, описание тула и подсказки отказов.

## Разбор

| Запись | Итог |
|---|---|
| `e1 . e2 . e3` | выражения по порядку; `.` — только отдельным словом |
| `x := <выражение>` | переменная программы `x` связана со значением; итог выражения — это значение |
| голое имя в начале выражения, связанное выше или параметром охватывающего блока | переменная: `c title print` |
| `@x` в значении ключа | значение переменной `x`; унарное после `@x` — ей (`id: @c id`) |
| `@x` в начале выражения | то же, что голое имя |
| голое связанное имя в значении ключа (`id: c`) | отказ «переменная в значении — `@c`; текст — `-- c`», код 2, до исполнения |
| `@x` несвязанной | отказ «`x` не связана; связаны: …», код 2, до исполнения |
| `x :=`, где `x` — сообщение корня (`kiten`, `it`, `help`) или слово грамматики | отказ «`kiten` — сообщение корня, выбери другое имя», код 2 |
| `^первое … последнее^` | один текст: слова через один пробел; `^одно^`; `^^` — пустой текст; слова грамматики внутри не толкуются; незакрытый — отказ «текст не закрыт», код 2 |
| слово текста, само начинающееся/кончающееся на `^` | `--` перед ним |
| `rem … end` | комментарий до `end`; незакрытый — до конца строки |
| `do :a :b … done` | блок с параметрами `a`, `b` |
| `do … done` | блок без параметров; `do … end` — группа (161); вид решает первый непарный закрыватель после `do` |
| внутри блока с параметрами `end` без своего `do` | закрывает выражение от начала тела блока (как от начала строки) |
| цепочка внутри блока без параметров | группой: `do do kiten ls end size print done` |
| `done` в значении вне открытого блока | литерал (`column: done`) |
| слово после `done` блока-значения | сообщение результату всего ключевого сообщения: `kiten ls collect: do :c c id done print` |
| `@c.title` | отказ «поле — унарным: `@c title`», код 2 |
| `title.` (точка приклеена) | `doesNotUnderstand` с подсказкой «`.` — отдельным словом» |
| число (`12`, `-3`, `2.5`) в начале выражения | число; в значении ключа команды — слово как есть |

Прочие правила 158–165 (ключи подряд — одно сообщение и деление получателем,
унарное после литерала — результату, `end` от начала строки, `--`, `stdin`,
`it`) действуют внутри каждого выражения и тела блока без изменений.

## Модель вычисления

- Все значения — объекты одного протокола «получить сообщение»: команды и
  группы реестра, результаты (коллекция, запись — `collection-protocol.md`),
  блоки, числа, тексты, `true`/`false`, `nil` (один null-объект). Команда
  реестра — объект, как прежде: вычислитель её не отличает.
- **Печать:** значение **последнего** выражения печатается видом по умолчанию
  (или форматом после `end`); `nil` не печатается. `print` печатает получателя
  (тем же видом, с переводом строки) и возвращает `nil`. `each:`, `timesRepeat:`,
  `to:do:` возвращают `nil`.
- Блок — замыкание (параметры, тело, захваченные переменные); `value`,
  `value:`, `value:value:`, `value:value:value:`. Число значений ≠ числу
  параметров — отказ «блок ждёт N значений, дано M», код 1. Итог блока —
  значение последнего выражения тела.
- Значение ключа **команды** — текстовый вид объекта (скаляр — его текст,
  запись с одним полем-скаляром — поле; прочее — прежний отказ «не скаляр»,
  `value-expression.md`). Значение ключа **базового объекта** — сам объект.
- Однокомандная строка, строка с группами и `it` — как прежде: итог (stdout,
  stderr, код, запись `it`) побайтово равен итогу до порции.

## Где исполняется

- Одно выражение без новых слов (`.`, `:=`, `^`, `@`, `rem`, блок `do :p`/`done`,
  число или переменная в начале) — прежний путь без изменений (голдены 158–165
  побайтово). Иначе строка — программа, и её целиком исполняет исполнитель.
- Команда, до которой дошла программа, уходит ядру кадром `line` (слова
  команды со значениями, уже вычисленными в текст, и `end json`); ядро
  исполняет её как отдельную строку прежней машиной (правила и дверь `ask` в
  момент отправки, своя запись журнала, `it`, свой исполнитель из пула) и
  отвечает кадром: данные JSON и путь команды, либо отказ (текст и код), либо
  код.
- Исполнитель программы место в пуле не занимает: предел `--lines` считает
  одновременные строки (программа — одна) и команды; вложенного ожидания нет.
- Вид по умолчанию последнего значения печатает исполнитель программы видом
  команды над данными (путь — из ответа кадра `line`), кадром `out`.

## Базовые объекты

| Получатель | Сообщения |
|---|---|
| булево | `ifTrue:`, `ifFalse:`, `ifTrue:ifFalse:` (блоки; невыбранная ветка — `nil`), `and:`, `or:` (блок, ленивое), `not` |
| число | `plus:`, `minus:`, `times:`, `div:` (целое с округлением вниз, как в Smalltalk: `10 div: 4` → 2, `-7 div: 2` → -4 — слепой замер `sonnet` ожидает именно так), `dividedBy:` (точное: `1250 dividedBy: 8` → 156.25); деление на 0 — отказ «деление на ноль», код 1, `greater:`, `less:`, `equals:`, `timesRepeat:`, `to:do:` (включительно) |
| текст | `equals:`, `includes:` (без учёта регистра, как `where:includes:`), `size`, `greater:`, `less:` (по кодовым точкам) |
| коллекция | протокол 162 плюс `each:`, `collect:`, `select:`, `reject:`, `detect:` (нет — `nil`), `inject:into:` |
| запись | поля унарными, `pick:` (162) |
| `nil` | `isNil` → `true`; прочее — `doesNotUnderstand` |
| любой | `print`, `isNil` (`false`), протокол отражения (160) |

Сравнение числа с текстом (`greater:`, `less:`) — отказ «сравнение числа и текста», код 1; `equals:` числа и текста — `false`. Блок печатается словом `блок`.
Число из поля записи JSON — число; строка — текст.

## Уступка и стек

- Пределов нет: ни шагов, ни глубины.
- Вычислитель уступает управление после каждой отправки сообщения: отмена
  (кадр `stop`, Ctrl+C) останавливает бесконечный цикл за ≤ 1 с, код 130.
- Стек вызовов — в куче, не на стеке JS: блок, вызывающий себя через
  переменную на глубину 100 000, завершается верно, исполнитель не падает.

## Ошибки

- `doesNotUnderstand` любого объекта — с «ближайшими» (порог — `objects.md`)
  и местом: номер верхнего выражения и селектор самого внутреннего блока —
  `выражение 2, блок each:: @c не понимает titel; ближайшие: title`.
  Одна ближайшая — `refusal.hint` с заменённым словом (165).
- Коды: 2 — разбор и отказ до исполнения; 1 — ошибка вычисления (включая
  отказ команды); 130 — отмена. Сделанное до ошибки не откатывается.
- Журнал вызовов: запись строки целиком и отдельная запись на каждую
  дошедшую команду реестра (`invoke-log.md`).
- Решение правил: каждая команда, до которой дошло вычисление, решается в
  момент отправки своим путём, как отдельная строка (дверь `ask-door.md`);
  обход до исполнения — порция 167.

## Граничные случаи

| Строка | Ожидается |
|---|---|
| `kiten ls` | как до порции (голдены 158–165) |
| `x := 5 . x plus: 2` | `7` |
| `x := 5 . x plus: 2 print` | `7` (print — результату `plus:`); итог `nil` не печатается |
| `3 greater: 2` | `true` |
| `3 greater: 2 ifTrue: do ^да^ print done` | `да` (деление склеенного: `greater:` — числу, `ifTrue:` — булеву) |
| `1 greater: 2 ifTrue: do ^да^ print done` | ничего, код 0 |
| `3 greater: 2 ifTrue: do ^да^ done ifFalse: do ^нет^ done` | `да` |
| `3 greater: ^a^` | «сравнение числа и текста», код 1 |
| `1 to: 3 do: do :i i print done` | `1`, `2`, `3` по строке |
| `3 timesRepeat: do ^x^ print done` | `x` трижды |
| `10 div: 0` | «деление на ноль», код 1 |
| `^готово к ревью^ size` | `14` |
| `^^ size` | `0` |
| `^a b` | «текст не закрыт», код 2 |
| `rem проверка end 2 plus: 2` | `4` |
| `x := kiten ls . x size` | число карточек |
| `x := kiten ls . x where: column is: review end each: do :c c title print done . x size print` | названия, затем число |
| `kiten ls collect: do :c c id done print` | ids; ничего сверх |
| `kiten ls inject: 0 into: do :a :c @a plus: 1 done` | число карточек |
| `kiten ls detect: do :c c id equals: 999999 done` | ничего (`nil`), код 0 |
| `kiten ls each: do :c kiten card id: @c id end comments size print done` | число комментариев на карточку |
| `kiten ls each: do :c kiten card id: c done` | «переменная в значении — `@c`; текст — `-- c`», код 2, ничего не исполнено |
| `kiten ls each: do :c @c titel print done` | `выражение 1, блок each:: запись не понимает titel; ближайшие: title`, код 1 |
| `b := do :x @x plus: 1 done . b value: 2` | `3` |
| `b := do :x :y @x done . b value: 1` | «блок ждёт 2 значений, дано 1», код 1 |
| `kiten := 1` | «`kiten` — сообщение корня, выбери другое имя», код 2 |
| `@y size` / `id: @y` | «`y` не связана; связаны: …», код 2 |
| `@c.title` | «поле — унарным: `@c title`», код 2 |
| `kiten ls where: column is: done` | `done` — литерал значения |
| `text: -- end` | литерал `end` (158) |
| `f := do :n @n less: 1 ifTrue: do 0 done ifFalse: do @f value: do @n minus: 1 end done done . f value: 100000` | `0`, исполнитель жив |
| `1 to: 1000000000 do: do :i i done` и Ctrl+C через 1 с | остановка ≤ 1 с, код 130 |
| `kiten ls . x` (несвязанная, начало выражения) | `doesNotUnderstand` корня с ближайшими, код 2 |
| `kiten ls size.` | подсказка «`.` — отдельным словом» |
| `2 print . 3` | `2`, затем `3` |

## Известные отклонения

- Блок без параметров, внутри которого нужна цепочка `end`, пишет её группой
  (`do do … end … done`): первый непарный закрыватель решает вид `do`.
