# Программа из stdin и из файла

Статус: к реализации — порция 170 (после 169).

## Назначение

Длинную программу неудобно и не всегда возможно передать словами командной
строки (предел `ARG_MAX`, кавычки оболочки). Программа приходит из stdin или
из файла; разбор — тот же, что у слов строки (`evaluator.md`).

## Контракт

| Вызов | Итог |
|---|---|
| `mpu` без слов, stdin не терминал | программа — stdin целиком (запрос ввода — `stdin-on-request.md`) |
| `mpu` без слов, stdin терминал | справка корня, как прежде |
| `mpu ask` без слов, stdin не терминал | программа из stdin с начальным `ask` |
| `mpu run: <путь> [<ключ>: <значение>]…` | программа из файла; ключи — параметры |
| `mpu ask run: <путь> …` | то же с начальным `ask` |
| MCP `["run:", "<путь>", …]` | то же; путь — абсолютный или от `cwd` вызова |

- **Текст → слова:** деление по пробельным символам (пробел, табуляция,
  перевод строки, `\r`); BOM в начале снимается; кодировка UTF-8. Своих
  кавычек нет: строка из терминала работает в файле и наоборот, `^…^` — для
  текста из нескольких слов.
- **Параметры:** внутри программы — `@<ключ>` (`@col`); значение — слово
  как есть. Использованный, но не переданный — отказ «программа ждёт
  параметр col: — mpu run: x.mpu col: …», код 2, до исполнения; переданный,
  но не использованный — не ошибка. Параметр не может называться как
  переменная, которой программа присваивает (`col :=`) — отказ, код 2.
- `ask` внутри текста программы первым словом — то же, что `mpu ask run:`.
- Предела длины нет (решение владельца); память — сторож (`line-executor.md`).
- Журнал вызовов: запись с путём файла (или `stdin`) и параметрами, без
  текста программы.

## Граничные случаи

| Дано | Ожидается |
|---|---|
| `printf 'kiten ls . 2 plus: 2' \| mpu` | вывод `kiten ls` не печатается, затем `4` (последнее выражение) |
| `mpu` в терминале без stdin | справка корня |
| файл `x.mpu`: `kiten ls where: column is: @col end size`; `mpu run: x.mpu col: review` | число карточек в `review` |
| `mpu run: x.mpu` | «программа ждёт параметр col: — mpu run: x.mpu col: …», код 2 |
| `mpu run: x.mpu col: review extra: 1` | как с одним `col:` |
| `mpu run: нет.mpu` | «нет файла нет.mpu», код 2 |
| файл с CRLF, BOM и `^готово к ревью^` | тот же итог, что у файла с LF без BOM |
| программа 200 КиБ (цикл из 10 000 выражений `1 plus: 1 .`) из stdin | исполняется, код 0 |
| программа с `kiten comment` без `ask` | адресный отказ двери, `hint` — `mpu ask run: x.mpu …` |
| MCP `["run:", "/abs/x.mpu", "col:", "review"]` | как CLI |
