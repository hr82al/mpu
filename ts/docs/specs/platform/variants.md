# Варианты команды вместо флагов поведения

Статус: реализовано — порция 164 (`30c12a9`, `48e2901`); принято 2026-09-23 хостом: гейты зелёные (тестов 2272, smoke 19/1), мутации M1–M7 красные. Спорные входы решены правилом «поведение — вариант, значение — ключ»: `is-active` — ключ; проекции `search`, `telegram send md`, `old`/`archived`/`failed`/`unresolved` — варианты.

## Назначение

Флаг, меняющий **поведение** команды (печатать вместо исполнения, локально,
все сразу, следить), — не значение, а другой способ исполнить команду. Такой
флаг становится **вариантом**: унарным сообщением объекту команды **до**
ключевого сообщения. Порядок строки: команда → варианты → ключи → `end` →
формат. Слепой замер `sonnet`: агент пишет `process dry target: 54`,
`logs portainer target: sl-1 since: 1h` сам (`mpu/docs/probes/…`, описание v3).

## Что становится вариантом

| Флаг | Вариант | Команды |
|---|---|---|
| `--dry-run`, `--dry` | `dry` | все, у кого есть |
| `--print` (печать команды вместо исполнения) | `print` | обёртки `sl-back`, `make-schema`, `api wb-*`, `xlsx open` |
| `--local` | `local` | обёртки `sl-back` (только вместе с `print`, как сейчас) |
| `--all` | `all` | `run-js`, `kiten spaces`, … |
| `--via ssh` / `--via portainer` / `--via loki` | `ssh` / `portainer` / `loki` | `ssh`, `run-js`, `logs` |
| `--follow` | `follow` | `logs` |
| `--detach` | `detach` | `run-js` |
| `--force`, `--forced`, `--force-fields` | `force` / `forced` / `force-fields` | `kiten time`, … |
| `--refresh` | `refresh` | `sheet get`, `sheet ls` |
| `--verbose` | `verbose` | `sql`, `sql-ro`, `process`, … |
| `--no-<что>` (`--no-comments`, `--no-images`, `--no-update`, `--no-move`, `--no-live`) | `no-<что>` | как сейчас |
| `--long`, `--literal`, `--timestamps`, `--keep`, `--parallel`, `--yes`, `--all-containers` | то же имя без `--` | как сейчас |

Правило для неназванного флага: булев вход, меняющий поведение, а не
передающий значение, — вариант с именем флага без `--`. Флаг, чьё значение —
данные (`--since`, `--limit`, `--client-id`), остаётся ключом. Спорный вход — в
отчёт, решает хост.

## Правила

- Вариант — унарное сообщение **объекту команды**, до первого ключа; вернёт
  объект команды «с этим вариантом». Несколько вариантов — подряд в любом
  порядке: `mpu process dry verbose target: 54`.
- Вариант после ключа по приоритету уходит литералу — это «унарное после
  литерала — результату» (158): там он не понят → отказ «вариант — до ключей:
  mpu process dry target: 54», код 2, ничего не исполнено.
- Прежний флаг (`--dry-run`) — снятое написание: отказ «вариант — словом до
  ключей: …» с готовой строкой.
- Несовместимые варианты (как сейчас: `portainer` и `follow` у `logs`,
  `local` без `print`) — прежний отказ, текст — в новой записи.
- Путь правила строки не меняется от варианта (`process <args>`): вариант —
  звено «в стороне», как формат. Но **в тексте вопроса двери вариант есть**:
  `mpu ask process all target: 54` спрашивает «выполнить mpu process all
  target: 54?» — человек подтверждает то, что исполнится (варианты меняют
  исполнение: `all`, `force`, `local`). Формат в текст вопроса не входит.
- Варианты не входят в `messages`: их перечисляет `variants`, в справке —
  раздел «Варианты»; дополнение после унарных звеньев предлагает `messages` и
  `variants`; узел снимка `tree.json` получает поле `variants` (у варианта — `input`: варианты одного входа исключают друг друга).
- `variants` протокола отражения (160) перечисляет варианты команды; справка —
  раздел «Варианты».

## Граничные случаи

| Строка | Ожидается |
|---|---|
| `mpu process dry target: 54` | как прежде `mpu process 54 --dry-run` (пара разбора) |
| `mpu process target: 54 dry` | отказ «вариант — до ключей: mpu process dry target: 54», код 2 |
| `mpu process target: 54 --dry-run` | отказ «вариант — словом до ключей: mpu process dry target: 54», код 2 |
| `mpu logs portainer target: sl-1` | как прежде `--via portainer` |
| `mpu logs portainer follow target: sl-1` | прежний отказ несовместимости, текст в новой записи |
| `mpu kiten card no-comments id: 1` | как прежде `--no-comments` |
| `mpu process variants` | `dry`, `print`, `local`, `verbose` … |
| `mpu ask process dry target: 54` | вопрос по правилу `process` (вариант пути не меняет) |
