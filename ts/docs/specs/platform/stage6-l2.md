# Порции L2a, L2b — отказы в виде «ошибка и как исправить»

Статус: к реализации (2026-10-08). План — `docs/plans/2026-10-08-tslibs-full-slicing.md`
(этап 6, L2); решение владельца 2026-10-07 (отказ — «что не так и как
сделать верно», без истории) и 2026-10-08 (объём узкий: ядро, история,
несуществующие команды). Опись снята с `main` `b430ae19`:
`stage6-l2-list.tsv` рядом (колонки: порция, класс, пакет, путь команды,
файл:строка, код, англ., текст, подсказка, заметка).

## Кто и зачем

Человек и агент читают отказ, чтобы сделать следующий шаг. Отказ, который
только называет ошибку, заставляет угадывать; отказ, который рассказывает
историю («снято», «прежнее имя», «выброшен»), — тратит внимание и устаревает;
отказ, который советует несуществующую команду (`mpu sheet sync`,
`mpu -h`), — ведёт в новый отказ.

## Правило текста

Отказ = **что не так** + **как исправить**, одной строкой (многострочный —
только список кандидатов под ней):

```
mpu: <где>: <что не так>; <как исправить>
```

- «Как исправить» — по убыванию ценности: готовая исправленная строка
  (`пиши: mpu kiten card id: 1`); недостающий ключ или значение с примером
  (`добавь id: <номер карточки>`); ближайшие слова (`ближайшие: card, cards`);
  справка места (`справка: mpu kiten card help`). Хотя бы одно есть всегда.
- Готовая строка, если она вычислима, — ещё и в `hint` объекта отказа
  (`platform/refusal-object.md`); иначе `hint: null`, совет — только в тексте.
- Никакой истории: слова «снят», «устарел», «прежн…», «теперь», «больше
  нет», «выброшен», «раньше», «retired», «dropped», `reason` «прежнее имя» —
  не появляются ни в тексте, ни в `reason`.
- Только живые команды и живая форма строки (`ключ: значение`): ни `-h`,
  ни `--help`, ни `mpu sheet sync`, ни `mpu sql` для записи (живой путь —
  `mpu ask sql`). Флаги `--x` в подсказках пакетов команд не трогаются —
  их переписывает L4 (вне этой спеки).
- Язык — язык остальных текстов той же команды (ядро — русский).
- Код выхода и вид отказа не меняются.

## Порция L2a — история, несуществующие команды, строка

Строки `L2a` списка: класс C (история), D (несуществующая команда или
форма — в том числе в пакетах команд), B в `tslibs/language` и
`ts/back/src/line`.

### Сценарии [S.n]

1. `mpu kiten selectors` (бывшее имя сообщения) → `mpu: kiten: selectors — не сообщение; пиши: mpu kiten messages`, код 2; `reason` — `не понимает`, `hint` — `mpu kiten messages`. То же для `respondsTo` → `understands`.
2. Ключ с другим именем (`keys.ts`: `--old`) → `mpu: <команда>: --old — не ключ; пиши: <имя>: <значение>` с готовой строкой в `hint`.
3. Имя из `registry/dropped.ts` (`mpu iu-wb …`) → `mpu: нет команды iu-wb; ближайшие: …; справка: mpu help`, код 2. В тексте нет решений и дат; причины снятия остаются комментарием кода, не выводом.
4. `mpu sql-ro target: sw sql: "select 1"` → `mpu: sql-ro: sw — не цель: БД воркспейсов отсюда недоступна; цель — номер клиента, sl-N или dev:N`, код 2 (то же в `call`).
5. `mpu nosuchcmd` → `mpu: нет команды nosuchcmd; ближайшие: …; справка: mpu help`, код 2 (вместо `No such command … Try 'mpu -h'`); корневая справка и справка команд не советуют `--help`.
6. `mpu sheet get spreadsheet: 999999 …` (клиент не найден) → `…; обнови список таблиц: mpu update` (вместо `mpu sheet sync`).
7. `mpu sql-ro …` с пишущим запросом → `…; запись — mpu ask sql target: … sql: "…"` (вместо `mpu sql`).
8. Описание тула MCP (`ts/mcp/src/tools.ts`) — без равенства `ключ: значение ≡ --ключ значение`.
9. Отказы строки (`language`, `line`): каждый текст списка получает хвост по правилу. Примеры: `у ключа id нет значения` → `…; добавь значение: id: <номер>`; `ключ id указан дважды` → `…; оставь один id:`; `после -- нет слова` → `…; -- экранирует следующее слово: text: -- end`; `ключ x ждёт true или false` → `…; пиши x: true`; `не понимает y` → `…; ближайшие: …` или `справка: mpu <путь> help`.
10. Голдены и тесты: каждый перерезанный текст — в обеих копиях (`docs/specs/fixtures/…` и `testdata/…`) побайтно; список перерезанных голденов — в отчёте.

## Общие сценарии

13. `rg -n "снят|устарел|прежн|теперь|больше нет|выброшен|раньше|retired|dropped|Try 'mpu -h'|mpu sheet sync" ts/back/src ts/cli/src ts/mcp/src ts/supervisor/src ts/web/src tslibs/*/src --glob '!*.test.ts'` — в выводимых текстах пусто (совпадения в комментариях и идентификаторах — в отчёте поимённо).

15. Списки случаев до = после, кроме перерезанных голденов (поимённо); гейты `ts/` и затронутых пакетов зелёные; новые версии пакетов — по договору пакета.

## Инварианты

- Коды выхода, виды отказов (`reason`) и поля объекта отказа не меняются,
  кроме снятия `reason` «прежнее имя» (заменяется на `не понимает`).
- Порядок проверок и место отказа не меняются: правится только текст.
