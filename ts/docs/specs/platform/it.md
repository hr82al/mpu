# `it` — последний результат вызывающего

Статус: к реализации — порция 163.

## Назначение

`back` держит результат последней строки каждого вызывающего; `mpu it md`
перерисовывает его без повторного запроса. Для тяжёлых `sql-ro` и `logs` — прямая
экономия времени и запросов к проду.

## Кто вызывающий

Первый кадр (`call-context.md`) получает необязательное поле `caller` —
строку, которой клиент называет себя:

| Клиент | `caller` |
|---|---|
| `mpu` (CLI) | `ppid:<номер родительского процесса>` — у строк одного терминала родитель один (его оболочка); путь терминала не берётся: он требовал бы нового права чтения `/proc/self/fd/0` |
| `mpu-mcp` | `mcp:<mcp-session-id>` |
| web | `web:<номер сессии cookie>` (хэш, не сама cookie) |

Поля нет — у строки нет вызывающего: её результат не запоминается, `it` для неё
— отказ.

## Поведение

- Результат-данные строки с кодом 0 запоминается для её `caller`, заменяя
  прежний; поток (`--follow`), отказ и код ≠ 0 — не запоминаются и прежний не
  трогают.
- `it` — сообщение корню: результат-данные, понимает форматы и протокол
  коллекции (162): `mpu it md`, `mpu it where: column is: review end size`.
- Хранится в памяти `back`, один результат на вызывающего; после перезапуска
  `back` — пусто. Вызывающих без строк 1 час — забываются.
- `it` не исполняет команду и правил не спрашивает (как `help`); само `it`
  результатом не становится (`it` дважды — тот же результат).

## Граничные случаи

| Строка | Ожидается |
|---|---|
| `mpu sql-ro target: 54 sql: "select 1 as n"`, затем `mpu it json` | тот же результат JSON, запроса к БД нет |
| `mpu it` в новом терминале | `mpu it: нет прошлого результата у этого вызывающего`, код 1 |
| `mpu kiten ls`, затем `mpu nope`, затем `mpu it size` | число карточек (отказ не заменяет) |
| MCP: строка в сессии A, `it` в сессии B | отказ «нет прошлого результата» |
| `mpu logs --follow …`, затем `mpu it` | прежний результат, поток не запомнен |
| `mpu it` после перезапуска `back` | отказ «нет прошлого результата» |

## Инварианты

- Результат одного вызывающего не виден другому.
- `it` ничего не исполняет.
