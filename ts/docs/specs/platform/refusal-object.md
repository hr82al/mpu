# Отказ — объект

Статус: к реализации — порция 165.

## Назначение

Отказы с подсказкой (158–164) сейчас — текст в stderr. Агент разбирает русский
текст, чтобы достать исправленную строку. Отказ становится объектом: MCP кладёт
его в `structuredContent`, агент берёт `hint` как есть. Печать в CLI не
меняется.

## Объект отказа

```json
{"refusal": {
  "reason": "значение — ключом",
  "hint": ["kiten", "comment", "id:", "55", "text:", "ok"],
  "candidates": [],
  "text": "mpu kiten comment: значение — ключом: mpu kiten comment id: 55 text: ok"
}}
```

| Поле | Источник |
|---|---|
| `reason` | вид отказа — короткая постоянная строка (не содержит значений строки) |
| `hint` | исправленная строка — массив слов, как `words` тула; нет подсказки — `null` |
| `candidates` | «ближайшие» (`doesNotUnderstand`, неоднозначная цель), иначе `[]` |
| `text` | тот же текст, что в stderr, без перевода строки |

Виды отказа, у которых есть `hint`: значение без ключа; флаг формата; короткий
флаг; snake_case; прежнее имя; вариант после ключа; вариант флагом; `ask`
нужен (дверь); частично понятое ключевое; `do` не в начале; слово-режим
значением (`logs ls`). Прочие — `hint: null`.

## Где виден

- MCP: ответ тула с `isError: true` получает в `structuredContent` поле
  `refusal` рядом с `stdout`, `stderr`, `exit`.
- `/line` с `Accept: application/json`: то же поле в собранном ответе.
- CLI: печать прежняя (stderr, код).

## Граничные случаи

| Дано | Ожидается |
|---|---|
| MCP `["kiten", "comment", "55", "ok"]` | `isError`, `refusal.hint` = `["kiten","comment","id:","55","text:","ok"]` |
| MCP `["kitn"]` | `refusal.reason` «не понимает», `candidates` = `["kiten"]`, `hint` = `["kiten"]` (одна ближайшая) |
| MCP `["sql", "target:", "1", "sql:", "update t"]` (ask без двери) | `hint` = `["ask", "sql", …]` |
| MCP отказ правил `deny` | `reason` «запрещено правилом», `hint: null` |
| успешная строка | поля `refusal` нет |
| CLI `mpu kiten comment 55 ok` | stderr и код — как до порции (голдены не меняются) |

## Инварианты

- `text` равен stderr отказа байт в байт без завершающего `\n`.
- `hint`, если есть, разбирается без отказа того же вида (подсказка не ведёт в
  тот же отказ).
- Описание тула `mpu` называет поле `refusal.hint` одной фразой (≤ 2048 байт).
