# Лишний `ask` на строке без записи

Статус: порция 167 (`047f8de`, `bd8056b`) принята 2026-09-23; составные строки (выражения, блоки, циклы) снимаются порцией L1 (`stage6-l1.md`) — остаётся случай лишнего `ask`.

## Назначение

Правила разрешений клиента видят только начало строки (`Bash(mpu ask *)`).
Строка, которая может дойти до записи, начинается словом `ask` (`ask-door.md`).
Начальный `ask` не разрешает, а объявляет: на строке, где нет ни одной
записи, он не отказ — решение владельца.

## Граничные случаи

Реестр поддельный: `kiten ls` — `allow`; `kiten comment` — `ask`; `sql` — `deny`.

| Строка | Ожидается |
|---|---|
| `ask kiten ls end size` | исполнение без вопросов, код 0 |

Составных строк (несколько выражений, группы, блоки) в языке нет: строка с
такой формой — отказ «не команда mpu» (`stage6-l1.md`).

## Инварианты

- Однокомандная строка — как в `ask-door.md` (голдены не меняются).
- Лишний `ask` на строке без записи — не отказ.
