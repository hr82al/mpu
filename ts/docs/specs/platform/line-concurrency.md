# Строки идут одновременно: каталог — у строки, не у процесса

Статус: реализовано — порция 150 (`be8f197` переукладка, `a80cd06` поведение); принято 2026-09-21: гейты зелёные (тестов 2240, smoke 21/1), пары с рабочей версией сошлись побайтно, живой прогон хостом на отдельном сервере — 17 строк разом дали 17 ответов с кодом 0 (предел 16), две одновременные строки увидели каждая свой каталог (одна упала с именем своего каталога, вторая отработала по дереву монорепо).

## Назначение

Сейчас строки исполняются по одной, и причина у этого одна: каталог строки
ставится сменой текущего каталога **всего процесса** (`platform/back-rpc.md`,
«Исполнение»). Пока это так, тонким клиентом не заменить старый `mpu`: у
человека одновременно открыты несколько терминалов, и долгая строка в одном
держит все остальные. Следующая порция (поток и отмена) без этого невозможна
вовсе: бесконечный `logs --follow` займёт очередь навсегда.

Порция переносит каталог из процесса в саму строку и снимает очередь. Поток
кусками, отмена и `--follow` — следующая порция; здесь их нет.

**Что она переопределяет в `platform/back-rpc.md`:** абзац «Исполнение» («строк
идёт по одной… исполнение меняет текущий каталог процесса») и инвариант «Строки
не исполняются одновременно». Остальное в той спеке остаётся как есть.

## Порядок работы

Порция состоит из двух коммитов, и первый — **переукладка**: каталог
становится параметром там, где сегодня берётся из процесса (`Deno.cwd()`), при
неизменном поведении и зелёных тестах. Только вторым коммитом снимается
очередь. Обратный порядок означал бы правку поведения на непереложенной
опоре.

## Что перестаёт быть состоянием процесса

Сегодня каталог держится одной сменой каталога процесса, и всё остальное
берёт его оттуда молча. После порции каталог переносится в строку в **четырёх**
местах, и каждое проверяется отдельно:

| Место | Сегодня | После порции |
|---|---|---|
| порт ввода-вывода команды (`cwd` у `CommandIo`) | каталог процесса | каталог своей строки |
| запуск подпроцесса (`ssh`, `docker`, `git`) | наследует каталог процесса | каталог передаётся запуску явно |
| журнал вызовов | каталог процесса на момент записи | каталог своей строки, пришедший вместе с ней |
| кэш-БД | один писатель по устройству очереди | ожидание занятой базы задано так же, как у правил (`PRAGMA busy_timeout`) |
| файловые порты команды (чтение и дозапись по пути) | путь от каталога процесса | путь от каталога своей строки (найдено при реализации: пятое место) |

Первое и третье — самые тихие: команда, читающая `io.cwd()`, и запись журнала
не упадут, а молча возьмут чужой каталог.

## Контракт

| Что | Сегодня | После порции |
|---|---|---|
| каталог строки | `Deno.chdir` процесса перед исполнением | значение у строки; процесс свой каталог не меняет |
| одновременность | вторая строка ждёт конца первой | до **16** строк одновременно; семнадцатая ждёт освобождения места |
| относительный путь аргумента | от каталога процесса | от каталога своей строки |
| подпроцесс (`ssh`, `docker`, `git`) | наследует каталог процесса | запускается в каталоге своей строки |
| временный файл команды | каталог временных файлов сервера | без изменений |
| `/rpc`, `/health` | от каталога не зависят | без изменений |

`Deno.chdir` в исполнении строки не вызывается ни разу: это и есть
наблюдаемое отличие (две строки с разными каталогами, идущие одновременно,
видят каждая свой).

## Инварианты

- Две одновременные строки с разными каталогами получают каждая свой:
  результат не зависит от того, шли они вместе или по очереди.
- Вывод строк не перемешивается: кадры каждой идут только в её канал.
- Итог строки (stdout, stderr, код) не зависит от числа соседних строк.
- Журнал вызовов пишет каталог **той** строки, которую записывает.
- Вопрос подтверждения и ожидание ответа человека не занимают места из
  шестнадцати: строка ждёт ответа до исполнения (`platform/back-rpc.md`).
- Предел одновременности — флаг сервера `--lines <число>` со значением по
  умолчанию 16; 0 и отрицательное — отказ запуска, как у `--port`.
- Запись в журнал вызовов целиком попадает в файл: две одновременно
  закончившиеся строки дают две целые записи, а не перемешанные куски.
  Механизм не назван: замер 2026-09-21 (восемь одновременных дозаписей по 1, 4
  и 16 МиБ **без всякого замка** дали восемь целых блоков) показал, что запись
  в файл, открытый на дозапись, уходит одним обращением к ядру и не режется.
  Замок на дозаписи не ставится: мутация «снять его» не краснеет, то есть он
  был бы кодом, которого ничто не проверяет. Замок на ротации остаётся.

## Граничные случаи и ошибки

| Дано | Ожидается |
|---|---|
| две строки: `sleep`-долгая в `/a` и быстрая в `/b` | быстрая отвечает, не дожидаясь долгой; каждая видит свой каталог |
| 17 строк разом | шестнадцать идут, семнадцатая начинает исполнение, как только освободилось место; её клиент видит только задержку |
| строка меняет каталог процесса своей командой | такой команды нет; если появится, каталог процесса всё равно не меняется |
| `cwd` не существует | `{"err": "mpu-back: нет каталога <cwd>\n"}`, `{"exit": 2}` — проверка уже сама по себе на строку, править её не нужно |
| команда читает файл по относительному пути | путь разрешается от каталога своей строки |
| подпроцесс печатает свой рабочий каталог | печатает каталог своей строки |
| строка А упала исключением | соседние строки доходят до конца, сервер жив |
| две строки пишут в кэш-БД одновременно | обе записи доходят (занятая база ждёт, а не отказывает); порядок не гарантирован |
| две строки печатают по мегабайту и кончаются разом | в журнале две целые записи, ни одна не разрезана другой |
| `deno task back --lines 0` | stderr `mpu-back: предел строк должен быть больше нуля`, код 2 |
| команда спрашивает свой рабочий каталог (`mpu code refs` с относительным путём) | видит каталог своей строки, а не каталог процесса |
| `mpu ssh` из строки с каталогом X | подпроцесс запускается в X |

## Golden-примеры

`fixtures/line-concurrency/`:

- `frames-parallel.json` — кадры двух одновременных строк с разными
  каталогами: у каждой свой вывод, порядок кадров внутри канала сохранён;
- `pairs.json` — пара «старый `mpu`, запущенный в каталоге X / строка с
  `cwd: X`» на команде, печатающей путь по относительному аргументу. Снимает
  исполнитель, хост замораживает при приёмке.

## Известные отклонения

- Порядок записей журнала вызовов между одновременными строками не определён:
  раньше он совпадал с порядком прихода, теперь — с порядком завершения.
  Вердикт **preserve** не применим: порядок никогда не был контрактом.
- Строка по-прежнему исполняется до конца, даже если клиент отключился;
  отмена — следующая порция.
- Целостность записи журнала держится поведением ядра, а не нашим замком.
  Сменится способ записи (сборка из нескольких обращений, файл на сетевой
  файловой системе) — инвариант рухнет молча, и тест «две записи по мегабайту
  разом» покраснеет не сразу. Проверять при любой правке записи журнала.
