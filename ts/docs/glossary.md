# Глоссарий — термин → имя в TS-коде

Изолированные Deno-сессии не видят кода друг друга; без глоссария
каждая переведёт термины по-своему. Новый термин — новая строка.

| Термин | Имя в коде | Пояснение |
| --- | --- | --- |
| брокер | `broker` | удалённый Go-сервис; единственный канал CLI наружу |
| операция | `operation` | именованный JSON-RPC-метод брокера (`<домен>.<действие>`) |
| реестр команд | `registry` | единый список команд: маршрутизация + справка |
| маршрут | `route` | способ исполнения команды: локально / операции брокера / legacy-делегация |
| legacy-делегация | `legacyDelegation` | исполнение не переехавшей команды через операцию брокера |
| токен | `token` | временный JWT из `auth.login`; хранится локально (0600) |
